# Getting started

You need the .NET 8 SDK and a host project that references the Dreambit engine.
Dreambit is source-first in this repository: game projects use a project
reference rather than a published package.

Work through these pages in order:

1. [Install and reference Dreambit](installation.md)
2. [Create your first game](first-game.md)
3. [Understand project and content layout](project-structure.md)

The repository's `Dreambit.Examples` project is the best executable companion
to this guide. It demonstrates UI, Pong, a space game, and particles.
